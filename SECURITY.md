# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for security vulnerabilities.

Email security@synorb.com with a description of the issue, steps to
reproduce, and the CLI version (`synorb --version`) and OS you tested on.
Include a proof of concept if you have one.

We will acknowledge your report and follow up with next steps. Please give
us reasonable time to investigate and release a fix before disclosing the
issue publicly.

## Supported versions

Only the latest published version of `@synorb/cli` on npm is supported.
Please upgrade before reporting an issue.
